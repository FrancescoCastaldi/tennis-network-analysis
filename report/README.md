## Compiling

From the repository root, with a LaTeX distribution and `latexmk` installed:

```bash
latexmk -pdf -interaction=nonstopmode -halt-on-error -cd report/main.tex
```

The committed tables and figures compile without rerunning the statistics. To regenerate them, run
`python -m tennis_networks.report_assets` (or `make report-assets`). Never edit them by hand.

The title block is produced by `\maketitle` from the author block in `main.tex`, which holds the names, the
degree programme and the student numbers, as the course template asks. No logo is used.

## Word count

```bash
python -m tennis_networks.wordcount
```

The command exits with status 1 above the 5,000-word limit. Use its output rather than a number written
in this file, because the count changes with every edit of the report.
