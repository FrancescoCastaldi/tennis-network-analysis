# Report

The LaTeX source of the project report, the tables and figures it includes, and the submission PDF.

## Contents

| Path | What it is |
|---|---|
| `main.tex` | Report source, following the official course template |
| `tables/` | LaTeX table fragments, generated by `report_assets` |
| `figures/` | Vector PDF figures (with PNG previews), generated by `report_assets` |
| `submission/` | The PDF submitted to the course, named as the exam rules require |
| `main.pdf` | Local or CI build of `main.tex`, ignored by Git |

## Compiling

From the repository root, with a LaTeX distribution and `latexmk` installed:

```bash
latexmk -pdf -interaction=nonstopmode -halt-on-error -cd report/main.tex
```

The committed tables and figures compile without rerunning the statistics. To regenerate them, run
`python -m tennis_networks.report_assets` (or `make report-assets`). Never edit them by hand.

The title block is produced by `\maketitle` from the author block: the names and degree programme, with the
student numbers read from `private/authors.tex` when that untracked file exists. No logo is used.

## Word count

```bash
python -m tennis_networks.wordcount
```

The command exits with status 1 above the 5,000-word limit. Use its output rather than a number written
in this file, because the count changes with every edit of the report.
