# Results

Frozen numerical outputs and graphical assets generated by the analysis pipeline.

## Structure

* `tables/`: CSV datasets containing computed network metrics, replication numbers, and hypothesis test statistics:
  * `global_measures.csv`: Topological metrics across all comparative networks.
  * `hypothesis_tests.csv`: Permutation test statistics for hypotheses H1 through H4.
  * `levels_tests.csv`: Multi-level hypothesis tests H6 (monadic), H7 (dyadic), H8 (mixed).
  * `triads_h5.csv`: Triad census ratio (030C/030T) hypothesis test results.
  * `structure_summary.csv`: HITS hubs/authorities, Borgatti-Everett core-periphery fit, small-world sigma.
  * `michieli_reproduction.csv`: Side-by-side comparison with published Michieli (2018) figures.
* `figures/`: Rendered Matplotlib plots (PDF and PNG formats).
* `null_models/`: Serialized null distributions and permutation matrices used for z-scores and empirical p-values.

All values are deterministic and reproducible using seed `20261115`.
