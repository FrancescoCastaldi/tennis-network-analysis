# Technical Documentation

Methodological specifications, data provenance records, and architectural decisions for the project.

## Index of Documents

* [`data.md`](data.md): Data provenance, acquisition protocols, file sizes, SHA-256 cryptographic hashes, and cross-source consistency checks between Michieli (2018) and tennis-data.co.uk.
* [`methodology.md`](methodology.md): Mathematical definitions of network models, topological metrics (cohesion, PageRank, k-cores, modularity, small-world, HITS, structural equivalence, triad census), null-model formulations, and hypothesis testing design (H1 to H8 across macro, monadic, dyadic, and mixed levels).
* [`decisions.md`](decisions.md): Architectural decisions records (ADR) detailing the code-first pipeline rationale, fast null models, multi-level hypothesis architecture, dual-mode execution notebooks, and collaborative team section ownership.
